# 主题色绑定逻辑调整计划

## 1. 需求分析

用户需要调整主题色绑定逻辑，具体目标如下：

1. **主题绑定到礼簿**：用户在创建礼簿时选择的主题应绑定到该礼簿，礼簿打开时始终使用该主题色。
2. **礼簿管理列表主题色标记**：主题色为喜庆红的数据列用淡红色标记，肃穆灰主题色的礼金簿用灰色标注。
3. **礼簿编辑功能**：在礼簿管理面板中添加编辑功能，允许用户重新编辑礼簿的事务名称、事务日期和主题色。

## 2. 现状分析

根据之前的开发工作，已经完成了以下基础工作：

* **后端数据库修改**：在 `database.rs` 中添加了 `Settings` 表，用于存储主题信息。

* **模型更新**：在 `models.rs` 的 `RecentDatabase` 结构中添加了 `theme` 字段。

* **API 命令修改**：

  * 更新了 `create_new_database` 命令，接收并存储 `theme` 参数。

  * 添加了 `get_database_theme` 和 `update_database_theme` 命令。

  * 更新了 `get_recent_databases` 命令，返回主题信息。

* **前端 API 封装**：在 `bridge.ts` 中添加了主题相关 API 调用。

* **前端类型定义**：在 `HomeView.vue` 和 `ManageBooksSection.vue` 中更新了 `Book/RecentBook` 接口，添加了 `theme` 字段。

## 5. 风险评估

1. **数据库兼容性**：确保现有礼簿在添加主题字段后仍能正常工作。
2. **主题切换逻辑**：确保礼簿打开时能正确切换到绑定的主题色。
3. **编辑功能验证**：确保编辑后的礼簿信息正确保存和显示。
4. **UI 一致性**：确保主题色标记在不同浏览器和设备上显示一致。

## 6. 预期结果

1. 用户在创建礼簿时选择的主题会绑定到该礼簿。
2. 礼簿管理列表中，不同主题的礼簿会有相应的颜色标记。
3. 用户可以通过编辑功能修改礼簿的事务名称、事务日期和主题色。
4. 礼簿打开时会自动使用绑定的主题色。
