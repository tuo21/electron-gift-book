# 礼金合集功能实现计划

## 需求分析

### 业务场景

在传统白事中，孝子的舅舅一方通常是一大家族一起前来吊唁。这一家人会事先把每个人的礼金统计在一起，用于请狮子或购买烟花爆竹等开支。录入人员需要誊录这份礼金列表，并注明：

* 这一批人的总账金额

* 开支金额（如请狮子、买烟花爆竹）

* 结余金额

### 核心功能需求

| 功能点    | 描述                           |
| ------ | ---------------------------- |
| 分组标记   | 在录入礼金时，通过起止符标记一批人的开始和结束      |
| 分组展示   | 在分组后面添加一列统计列，显示分组统计信息（小计、备注） |
| 分组统计   | 竖排显示分组总账、开支、结余               |
| 手动开支明细 | 除自动统计外，支持手动输入支出明细，竖排显示       |
| 临时结束   | 暂停当前分组录入，先录入零散客人，之后可继续       |
| 总统计体现  | 在总统计信息中增加开支和结余（统计所有分组的总数）    |

## 技术方案

### 方案选择

采用在现有 `Record` 表中添加分组相关字段的方式，避免创建新表带来的复杂度。

### 新增字段设计

| 字段名                  | 类型                                          | 说明                       |
| -------------------- | ------------------------------------------- | ------------------------ |
| `groupId`            | `number`                                    | 分组ID，同一组的记录拥有相同的groupId  |
| `groupRole`          | `'start' \| 'end' \| 'member' \| 'summary'` | 在分组中的角色：起始标记、结束标记、成员、统计列 |
| `groupTotal`         | `number`                                    | 分组总账金额（仅统计列记录存储）         |
| `groupExpense`       | `number`                                    | 分组开支金额（仅统计列记录存储）         |
| `groupBalance`       | `number`                                    | 分组结余金额（仅统计列记录存储，自动计算）    |
| `groupExpenseDetail` | `string`                                    | 开支明细备注（手动输入）             |

### 数据结构设计

```typescript
interface Record {
  // 原有字段...
  groupId?: number           // 分组ID
  groupRole?: 'start' | 'end' | 'member' | 'summary'  // 分组角色
  groupTotal?: number        // 分组总账
  groupExpense?: number      // 分组开支
  groupBalance?: number      // 分组结余
  groupExpenseDetail?: string // 开支明细
}
```
