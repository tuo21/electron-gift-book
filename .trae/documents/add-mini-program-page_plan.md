# 添加"小程序"导航页面计划

## 1. 需求分析

用户希望在首页（HomeView.vue）的左侧导航菜单栏中增加一栏"小程序"，点击后进入一个新页面，展示：
- 小程序二维码（复用关于页面的二维码图片）
- 小程序功能介绍

### 小程序功能要点（用户提供）
- 基本功能与本软件相似：礼簿管理、快速搜索名称获取收礼信息
- 新增送礼支出记录功能，收礼和送礼信息一目了然
- 可将本软件导出的 Excel 表格快速导入小程序
- 便携方便

## 2. 项目现状分析

### 2.1 现有导航结构
首页 `HomeView.vue` 的左侧导航栏包含 4 个页面：
| ID | 页面 | 组件 |
|----|------|------|
| dashboard | 首页 | DashboardPage.vue |
| instructions | 使用说明 | InstructionsPage.vue |
| settings | 设置 | SettingsPage.vue |
| about | 关于 | AboutPage.vue |

### 2.2 导航实现方式
- `HomeView.vue` 中使用 `navItems` 数组定义菜单项
- 通过 `currentPage` 响应式变量控制当前页面
- 使用 `v-if` 条件渲染不同页面组件

### 2.3 二维码资源
AboutPage.vue 中使用的小程序二维码图片路径：
```
/images/小程序码.jpg
```

## 3. 修改方案

### 3.1 创建新页面组件
**文件**: `src/components/home/MiniProgramPage.vue`

功能：
- 顶部标题：推荐小程序 / 小程序二维码
- 展示小程序二维码图片（复用 `/images/小程序码.jpg`）
- 展示小程序功能介绍（使用列表格式）
- 样式风格与现有页面保持一致

### 3.2 修改 HomeView.vue
需要做以下改动：

1. **添加 import 语句**：引入 MiniProgramPage 组件
2. **扩展 navItems 数组**：新增 `{ id: 'mini-program', label: '小程序', icon: 'wechat' }`
3. **添加页面渲染分支**：新增 `v-else-if="currentPage === 'mini-program'"`

### 4.2 修改 HomeView.vue

| 修改位置 | 说明 |
|---------|------|
| import 区 | 新增 `import MiniProgramPage from './MiniProgramPage.vue';` |

| template 页面渲染区 | 新增 `MiniProgramPage` 的 v-if 分支 |

## 5. 风险评估

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| 图标缺失 | 'wechat' 图标不存在，显示异常 | 检查 IconSvg.vue 支持的图标列表，选择合适的图标 |
| 图片路径错误 | 二维码图片无法显示 | 确认 `/images/小程序码.jpg` 路径正确 |
| 样式不一致 | 新页面与其他页面风格不同 | 参考 AboutPage.vue 的 CSS 类和布局方式 |
